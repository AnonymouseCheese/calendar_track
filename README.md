# Calendar Track

A small private calendar and job-notes app for the phone.

- Month calendar with a note for each day
- Active jobs with notes, plus earlier rounds' notes for recurring jobs
- Old jobs, searchable

**Your notes never leave your device.** This repository holds only the empty
app. Everything you type is saved in your phone's own storage, and the app is
blocked from sending data anywhere. Each person who installs it gets their own
separate, empty copy.

## Install on iPhone

1. Open https://anonymousecheese.github.io/calendar_track/ in **Safari**.
2. Tap **Share**, then **Add to Home Screen**.
3. Always open it from the Home Screen icon.

Use **Backup & settings > Make a backup file** regularly. Deleting the Home
Screen icon deletes its notes.
